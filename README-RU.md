# Система бронирования слотов времени (Booking System)

Приложение для бронирования 30-минутных временных слотов на Next.js с красивым интерфейсом на Tailwind CSS.

## ✨ Возможности

- 📅 **Интерактивный календарь** - просмотр месяца с выбором свободных дат
- ⏰ **30-минутные слоты** - работающие часы с 9:00 до 18:00
- 📝 **Бронирование** - введение имени и выбор времени
- 👥 **Список бронирований** - отображение всех забронированных слотов
- 🗑️ **Отмена** - возможность отменить уже забронированное время
- 💾 **Сохранение** - данные сохраняются в localStorage браузера
- 🎨 **Современный дизайн** - красивый UI с Tailwind CSS и иконками от Lucide

## 🎯 Как использовать

1. **Откройте календарь** - вы увидите месячный календарь с доступными днями
2. **Выберите дату** - кликните на желаемый день
3. **Выберите время** - выберите из доступных 30-минутных слотов с 9:00 до 18:00
4. **Введите имя** - укажите ваше имя
5. **Подтвердите** - нажмите кнопку "Забронировать"
6. **Отменить** - используйте корзину (🗑️) в списке бронирований для отмены

## 🔧 Технологии

- **Next.js 16** - современный React фреймворк
- **TypeScript** - типизация JavaScript
- **Tailwind CSS** - утилит-ориентированный CSS фреймворк
- **Lucide Icons** - красивые SVG иконки
- **React Hooks** - useState, useEffect для управления состоянием
- **localStorage** - кэширование данных в браузере

## 📋 Детали реализации

### Функциональность

- ✅ Календарь с навигацией по месяцам
- ✅ Отключение прошлых дат (нельзя забронировать в прошлое)
- ✅ 18 слотов в день (9:00-18:00, каждые 30 минут)
- ✅ Отображение занятых слотов
- ✅ Форма с валидацией (имя и время обязательны)
- ✅ Сохранение бронирований в localStorage
- ✅ Отмена бронирований с удалением из памяти
- ✅ Сортировка бронирований по дате и времени

### Стили

- Градиентный фон (синий → индиго)
- Исп-адаптивный дизайн (Tailwind grid)
- Цветовые указатели:
  - 🔵 Синий - сегодня
  - 🟢 Зелёный - забронировано
  - ⚪ Белый - свободно
  - ⚫ Серый - недоступно (прошлое)

## 🔐 Безопасность данных
