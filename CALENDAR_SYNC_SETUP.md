1. **API Маршрут**: Створено `/src/app/api/calendar/events/route.ts`
   - Читає Google Calendar за допомогою Service Account
   - Повертає масив зайнятих слотів на формат `[{date: "YYYY-MM-DD", time: "HH:MM"}, ...]`

   GOOGLE_SERVICE_ACCOUNT_EMAIL=calendar-reader@constructor-488411.iam.gserviceaccount.com

5. **Облікові Дані**: Зберігаються в `google-service-account.json`
   - Файл ніколи не комітьте до git (вже в `.gitignore`)
   - Содержит приватний ключ для Service Account доступу

## ⚠️ Важливий Крок: Поділіться Календарем з Service Account

Для того щоб API могла читати ваш календар, необхідно дати дозвіл Service Account:

### Крок 1: Отримайте Service Account Email

З файлу `google-service-account.json`, знайдіть поле `client_email`:
```
calendar-reader@constructor-488411.iam.gserviceaccount.com
```

### Крок 2: Поділіться Календарем

1. Йдіть на https://calendar.google.com
2. Знайдіть свій календар (habuzovs@gmail.com) у лівій панелі
3. Клікніть на три точки поруч з календарем → "Settings and sharing"
4. Прокрутіть вниз до "Share with specific people"
5. Клікніть "Add people"
6. Вставте `calendar-reader@constructor-488411.iam.gserviceaccount.com`
7. Дайте дозвіл "See all event details" (або вище)
8. Клікніть "Share"

### Крок 3: Перевірте Налаштування

Переконайтеся, що:
- ✅ Service Account має доступ до календаря
- ✅ `.env.local` містить правильний `GOOGLE_CALENDAR_ID`
- ✅ `google-service-account.json` міститься в кореневому каталозі проекту

## 🧪 Тестування

Після поділу календаря з Service Account:

1. Запустіть `npm run dev`
2. Відкрийте http://localhost:3000
3. Натисніть кнопку "Синхронізувати" в синій панелі Google Calendar
4. Перевірте на наявність червоних слотів (зайняті часи з вашого календаря)

### Перевірка API Безпосередньо

Відкрийте в браузері:
```
http://localhost:3000/api/calendar/events?month=2&year=2025
```

Повинна повернути JSON:
```json
{
  "busySlots": [
    {"date": "2025-03-16", "time": "10:00"},
    {"date": "2025-03-16", "time": "14:30"}
  ]
}
```

## 🐛 Розв'язання Проблем

### API Повертає Помилку 500

**Проблема**: Ймовірно, Service Account не має доступу до календаря

**Рішення**:
1. Перевірте, що ви поділилися календарем (див. "Крок 2" вище)
2. Очистіть localStorage: `localStorage.clear()` в консолі браузера
3. Перезавантажте сторінку

### API Повертає Порожній Масив

**Проблема**: У календарі немає события, або вони у неправильному форматі

**Рішення**:
1. Додайте кілька событий у Google Calendar
2. Переконайтеся, що события мають час (не "весь день")
3. Натисніть "Синхронізувати" ручно

### Часи Невідповідні

**Проблема**: Google может повертати часи у UTC, а не у вашій часовій зоні

**Рішення**:
- В даній версії API використовує локальний часовий пояс браузера
- Для точних часів, дайте мені знати, і я додам підтримку часових поясів
