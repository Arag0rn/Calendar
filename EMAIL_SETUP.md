# Как получить App Password для Gmail SMTP

## Шаг 1: Откройте Google Account Security

Перейдите на: https://myaccount.google.com/apppasswords

(Может потребоваться войти в `habuzovs@gmail.com`)

## Шаг 2: Выберите приложение и устройство

В появившихся выпадающих меню выберите:

1. **Приложение (Application)**: 
   - Выберите "Mail"

2. **Устройство (Device)**:
   - Выберите "Windows Computer" (или любовее другое)

## Шаг 3: Получите пароль

Google сгенерирует для вас 16-символьный пароль со спецсимволами. Например:
```
abcd efgh ijkl mnop
```

## Шаг 4: Добавьте в `.env.local`

Откройте файл `.env.local` в папке проекта и найдите строку:
```
SMTP_PASSWORD=your_app_password_here
```

Замените на полученный пароль (включая пробелы):
```
SMTP_PASSWORD=abcd efgh ijkl mnop
```

## Шаг 5: Перезагрузите сервер

Если сервер работает, перезагрузите его:

```bash
# Остановите текущий dev сервер (Ctrl+C)
# Затем запустите заново
npm run dev
```

## Шаг 6: Тестируйте

1. Откройте админский режим сайта (если у вас `NEXT_PUBLIC_ADMIN_MODE=true`)
2. Забронируйте слот (введите свой email для теста)
3. Проверьте почту (может быть в спаме, так что проверьте Spam папку)

Вы должны получить 2 письма:
- На тестовый email (для клиента)
- На `habuzovs@gmail.com` (для админа)

---

## Если не работает?

### Проблема: "Invalid login credentials"

- Убедитесь, что используете **App Password**, а не обычный пароль аккаунта
- App Password должен быть сгенерирован специально для этого приложения

### Проблема: "Authorization required"

- Двухфакторная аутентификация должна быть **включена** на Google Account

### Проблема: "SMTP connection timeout"

- Проверьте переменные:
  ```
  SMTP_HOST=smtp.gmail.com
  SMTP_PORT=587
  ```

### Смотрите логи сервера

В консоли, где запущен `npm run dev`, после попытки бронирования ищите сообщение:
```
[Email] Sent to: user@example.com Message ID: ...
```

Если видите `[Email] Failed to send:`, то ошибка в конфигурации.
