# Планы публикации приложения

## Два режима работы

### 1. **Админский режим** (для вас)
Параметр `.env.local`:
```
NEXT_PUBLIC_ADMIN_MODE=true
```
✓ Видна кнопка "Синхронізувати" (обновить занятые времена)
✓ Видна кнопка удаления бронирований
✓ Управление всеми бронированиями

### 2. **Публичный режим** (для клиентов)
Параметр `.env.local`:
```
NEXT_PUBLIC_ADMIN_MODE=false
```
✓ Скрыта кнопка синхронизации
✓ Скрыта кнопка удаления бронирований
✓ Только просмотр доступных слотов и бронирование

## Конфигурация для производства

### Шаг 1: Отправка уведомлений по Email

#### Получение Password для Gmail

1. Откройте https://myaccount.google.com/apppasswords
2. Используйте аккаунт `habuzovs@gmail.com`
3. Выберите "Mail" → "Windows Computer" (или ваше устройство)
4. Google сгенерирует 16-символьный пароль
5. Скопируйте пароль и добавьте в `.env.local`:

```
SMTP_PASSWORD=xxxx xxxx xxxx xxxx
```

#### Проверка Email-конфигурации

После сохранения пароля попробуйте забронировать слот в админском режиме. Вы должны получить письма:
- На почту клиента (подтверждение бронирования)
- На `habuzovs@gmail.com` (уведомление о новом бронировании)

### Шаг 2: Переключение в публичный режим

1. Откройте `.env.local`
2. Измените:
```
NEXT_PUBLIC_ADMIN_MODE=false
```
3. Перезагрузите сервер

### Шаг 3: Деплой на хостинг

#### Рекомендуемые платформы:

**а) Vercel (самый простой)**
```bash
npm install -g vercel
vercel
```
Автоматически деплоит из GitHub, поддерживает переменные окружения

**б) Railway, Render, Heroku**
- Залейте код на GitHub
- Подключите репо в интерфейсе хостинга
- Добавьте переменные окружения

#### Переменные для хостинга:

```
# Google Configuration
NEXT_PUBLIC_GOOGLE_CLIENT_ID=...
GOOGLE_CALENDAR_ID=habuzovs@gmail.com
GOOGLE_SERVICE_ACCOUNT_EMAIL=calendar-reader@...

# Email
ADMIN_EMAIL=habuzovs@gmail.com
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=habuzovs@gmail.com
SMTP_PASSWORD=xxxx xxxx xxxx xxxx

# Public Mode
NEXT_PUBLIC_ADMIN_MODE=false
```

#### Файл `google-service-account.json`:

К сожалению, этот файл нужен на сервере. Два варианта:

**Вариант 1 (Simpler)**: Добавьте в `.env.local` на хостинге (как base64):
```bash
# Локально
cat google-service-account.json | base64

# На хостинге добавьте переменную
GOOGLE_SERVICE_ACCOUNT_JSON=<base64-encoded-content>
```

Затем обновите API routes чтобы декодировать это.

**Вариант 2**: Используйте Google Cloud Storage или secure key management

### Шаг 4: DNS и домен

Если у вас есть домен (например, booking.example.com):
1. На Vercel/хостинге добавьте домен в настройки
2. Обновите DNS записи согласно инструкциям
3. Готово!

## Техническая справка

### Как работает система

1. **Клиент** открывает публичную страницу
2. **Выбирает дату и время** (30-минутный слот)
3. **Вводит имя и email**
4. **Система создает событие** в вашем Google Calendar
5. **Отправляет письма**:
   - Клиенту: подтверждение бронирования + Google Meet ссылка
   - Вам: уведомление о новом бронировании
6. **Google Calendar синхронизирует** с календарем (если используется)

### Что хранится?

- **Все данные** → Google Calendar вашего аккаунта
- **Письма** → История в Gmail (SMTP_USER)
- **No cookies, no localStorage** → Только Google Calendar

### Безопасность

- Service Account только для **чтения/записи** в календарь
- Email и пароль хранятся в переменных окружения (не в коде)
- Google Meet ссылки генерируются автоматически

## Проблемы и решения

### Q: Письма не приходят?
**A**: Проверьте:
1. `SMTP_PASSWORD` - это app password, не обычный пароль
2. Gmail разрешает "Less secure app access" (уже настроено для app passwords)
3. Консоль сервера показывает ошибки? Проверьте логи

### Q: Занятые времена не обновляются?
**A**: 
1. Убедитесь, что Google Calendar поделена с Service Account
2. Дайте разрешение "Make changes to events"
3. Нажимайте кнопку синхронизации в админском режиме

### Q: Как изменить рабочие часы?
**A**: В файле `src/components/SlotPicker.tsx`, строка ~25:
```js
for (let hour = 9; hour < 18; hour++) { // 9:00 - 18:00
```
Измените 9 и 18 на нужное время

### Q: Как изменить язык?
**A**: Все тексты на русском/украинском, жестко прописаны в компонентах. Нужна будет небольшая рефакторинг для i18n
